# Krishna Bansal Portfolio

A static, responsive portfolio website built with plain HTML, CSS and JavaScript. No paid website builder and no build step are required.

## Preview locally
Open `index.html` directly in a browser, or run a simple local server from this folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Publish for free
### GitHub Pages
1. Put all files in this public repository.
2. Settings → Pages.
3. Deploy from branch → `main` / root.
